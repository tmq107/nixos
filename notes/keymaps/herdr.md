# Herdr Keymap

## Prefix
| Key | Action |
|-----|--------|
| `Ctrl+Space` | Prefix (custom) |

## Session
| Key | Action |
|-----|--------|
| `Prefix + q` | Detach |
| `Prefix + r` | Reload config |

> Reload from terminal: `herdr server reload-config`

## Tabs
| Key | Action |
|-----|--------|
| `Prefix + c` | New tab |
| `Prefix + n` | Next tab |
| `Prefix + p` | Previous tab |
| `Prefix + 1..9` | Switch to tab 1..9 |

## Panes
| Key | Action |
|-----|--------|
| `Prefix + v` | Split vertical (new pane on right) |
| `Prefix + h` | Split horizontal (new pane below) |
| `Prefix + z` | Zoom pane |
| `Prefix + [` | Copy mode |
| `Prefix + Shift+r` | Resize mode |
| `Prefix + b` | Toggle sidebar |

## Navigation
| Key | Action |
|-----|--------|
| `Prefix + Left` | Focus left pane |
| `Prefix + Right` | Focus right pane |
| `Prefix + Up` | Focus upper pane |
| `Prefix + Down` | Focus lower pane |

## Workspaces
| Key | Action |
|-----|--------|
| `Prefix + Shift+1..9` | Switch workspace 1..9 |
| `Prefix + u` | Previous workspace |
| `Prefix + i` | Next workspace |

## Behavior
| Setting | Value |
|--------|-------|
| New pane/tab cwd | Follow current pane/workspace |
| Mouse capture | Enabled |
| New tab prompt | Disabled |
